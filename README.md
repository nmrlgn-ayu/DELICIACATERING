# Deli Catering — Sistem Pengeluaran Kas

```
deli-catering/
├── backend/            # SQL Supabase (tabel, data awal, RLS)
│   ├── deli_catering_v2.sql
│   └── README.md
├── frontend/           # Aplikasi web
│   ├── index.html
│   ├── style.css
│   ├── script.js
│   └── README.md
├── index.html          # Redirect ke frontend/ (untuk GitHub Pages)
└── README.md
```

## Menjalankan
1. Jalankan `backend/deli_catering_v2.sql` di Supabase SQL Editor.
2. Aktifkan GitHub Pages (Settings → Pages → branch `main`, folder `/root`).
3. Buka `https://nmrlgn-ayu.github.io/DELICIACATERING/`.
